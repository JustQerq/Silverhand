# Project Silverhand
Project Silverhand implements Computer vision powered software to control a robotic arm.

A single web-cam is used to detect the user's hand and mimic its movement in the robotic arm.
Data is processed using Python scripts, hand recognition is based on the Google Mediapipe hand pose model.
As an additional feature, a script for playing Rock, Paper, Scissors with the user was developed.

Robotic arm used to test this software was 3d printed using the open-source project InMoov.
It's operated using 9 servos total (5 for the fingers, 1 each for the wrist, elbow, forearm and shoulder).
Servos are controlled using 2 Arduino Uno microcontrollers.
